# TAX-CRM

## Description
Це веб-додаток CRM-системи, створений на Flask, під керівництвом Vadim, розробляв Коловейдо Влад. За порадою мого наставника, зробив повний редизайн навчального проєкту, який виконувався на його репозиторію командою із 4 людей. Було перероблено інтерфейс, змінено та перероблено усі наявні сторінки, було залишено тілько бд на MySQL, а також логіку входу у систему. Призначений для управління лідами, користувачами, активністю та іншими даними. Проєкт містить логіку автоматичної ініціалізації бази даних, тому не потребує ручного створення таблиць або наповнення.

## Functions
- Управління клієнтами
- Аналітика продажів
- Автоматизація процесів
- Інтеграція з іншими сервісами

## Requirements
- Python 3.8
  - numpy (default)
  - json (default)
  - math (default)
- Django 3.x
- Flask v.x
- React v.x
- MySQL v.x

## Install
### Кроки для запуску проекту:
### 1. Клонування репозиторію

```bash
git clone https://github.com/Koloveydo/my-test-tax-crm
```

### 2. Зайти на потрібну папку для запуску

```bash
cd \extra-db\tax-crm\docs\v1\app
```

### 3.Створення віртуального середовища

``` bash
python -m venv venv
source venv/bin/activate  # для Linux/macOS
venv\Scripts\activate     # для Windows
```

### 4. Запуск

```bash
python app.py
```
Переконайтесь, що http://localhost:8080 не заповнений в іншому випадку очистіть його або змініть у app.py
