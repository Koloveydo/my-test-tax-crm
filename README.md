# TAX-CRM

## Description
Це власна CRM система, розроблена для управління взаємовідносинами з клієнтами, яка забезпечує зручний інтерфейс для менеджерів, аналітику і автоматизацію робочих процесів.

## Functions
- Управління клієнтами
- Аналітика продажів
- Автоматизація процесів
- Інтеграція з іншими сервісами

## Requirements
- Python 3.8
  - numpy (default)
  - json (default)
  - math (default)
- Django 3.x
- Flask v.x
- React v.x
- MySQL v.x

## Install
### Кроки для запуску проекту:
1. Клонувати репозиторій:
```bash
git clone https://github.com/GoldSatan/tax-crm
```

## Using
1. Зареєструйтеся або увійдіть у систему як адміністратор.
2. Додайте нових клієнтів та керуйте взаємодією з ними.
3. Аналізуйте результати за допомогою вбудованих інструментів аналітики.
